# Основы Git и GitHub

Этот документ — краткий конспект по работе с системой контроля версий **Git** и платформой **GitHub**. Здесь собраны основные команды, понятия и шаги для старта.

---

## Основные понятия

- **Git** — распределённая система контроля версий.
- **Репозиторий (repo)** — папка с проектом, отслеживаемая Git.
- **Commit** — «снимок» состояния проекта в определённый момент времени.
- **Branch (ветка)** — независимая линия разработки.
- **Remote** — удалённый репозиторий (например, на GitHub).
- **Push / Pull** — отправка изменений на удалённый репозиторий / получение изменений из него.

---

## Основные команды Git

| Команда | Назначение |
|--------|------------|
| `git init` | Инициализация нового репозитория |
| `git clone <url>` | Клонирование удалённого репозитория |
| `git status` | Показать текущее состояние рабочей директории |
| `git add <file>` | Добавить файл в индекс (staging area) |
| `git add .` | Добавить все изменения в индекс |
| `git commit -m "сообщение"` | Создать коммит с описанием |
| `git log` | Просмотр истории коммитов |
| `git branch` | Посмотреть список веток |
| `git checkout <branch>` | Переключиться на ветку |
| `git checkout -b <new-branch>` | Создать и переключиться на новую ветку |
| `git merge <branch>` | Влить изменения из указанной ветки в текущую |
| `git push` | Отправить локальные коммиты в удалённый репозиторий |
| `git pull` | Получить и слить изменения из удалённого репозитория |

## Как начать новый проект

1. **Создайте папку проекта** и откройте терминал в ней.
2. ### Выполните:
   ```bash
   git init


## Инициализируйте Git-репозиторий:
```bash

git init
```
3. ### Добавьте файлы (например, index.html, README.md) и подготовьте их к коммиту:

```bash

git add .
```

4. ### Сделайте первый коммит:

```bash

git commit -m "Initial commit"
```

5. ### Создайте репозиторий на GitHub (без README, если проект уже локальный).
6. ### Свяжите локальный и удалённый репозитории:

```bash


git remote add origin git@github.com:ваш-логин/название-репо.git
```

7. ### Отправьте код:

```bash


git push -u origin main
```
## _💡 Ветка по умолчанию может называться main или master — уточните в настройках GitHub._ 

# 💻 Что такое Git Bash?
## Git Bash — это терминал для Windows, который эмулирует Unix-среду и позволяет использовать все команды Git и bash.

### Зачем он нужен?

- На Windows стандартная командная строка не всегда корректно работает с Git.
- Git Bash предоставляет привычную среду разработчика (как в Linux/macOS).

### Установка

- Перейдите на https://git-scm.com/downloads
- Скачайте и установите Git для Windows — Git Bash установится автоматически.
- Запускайте через «Пуск» → Git Bash.

```✅ После установки вы можете использовать все Git-команды прямо в этом окне!```

## 🔑 Настройка SSH-ключей для GitHub

_SSH-ключи позволяют подключаться к GitHub без ввода логина и токена при каждом push/pull._

**Шаги по настройке:**

1. ### Проверьте, есть ли уже ключи:

```bash

ls -al ~/.ssh
```

*Ищите файлы вроде id_ed25519.pub или id_rsa.pub.*

2. ### Создайте новый ключ (если нет):

```bash

ssh-keygen -t ed25519 -C "ваш@email.com"
```

*Нажимайте Enter, чтобы принять настройки по умолчанию.*

3. ### Запустите агент и добавьте ключ:

```bash

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

4. ### Скопируйте публичный ключ:

```bash

cat ~/.ssh/id_ed25519.pub
```

*Скопируйте весь вывод (начинается с ssh-ed25519 ...).*

5. ### Добавьте ключ на GitHub:
* _Зайдите в Settings → SSH and GPG keys → New SSH key_
* _Вставьте скопированный ключ и сохраните._

6. ### Проверьте подключение:

```bash

ssh -T git@github.com
```

**Успешный ответ:**

```Hi <ваш-логин>! You've successfully authenticated...```

**✅ Теперь вы можете клонировать и пушить через SSH:**

```git clone git@github.com:ваш-логин/репо.git ```

## 💡 Советы на каждый день
- Пишите ясные сообщения коммитов: «Добавил кнопку отправки», а не «фикс».
- Делайте коммиты маленькими и по одному смыслу.
- Используйте .gitignore, чтобы не коммитить мусор (node_modules/, .env, логи и т.д.).
- Перед git push делайте git pull, чтобы избежать конфликтов.
- Не бойтесь веток — они дешёвые и безопасные!
